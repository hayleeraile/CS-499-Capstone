Software Design and Engineering

This enhancement focused on improving the design, maintainability, usability, and overall structure of the InventoryPRO application.

Software Design and Engineering Narrative

Artifact Description and Justification

The artifact that I chose is my InventoryPRO application. It is a mobile application that was designed on the Android platform that manages a user’s inventory. It was created for the CS-360 class in December of 2025.

I chose to use this artifact for category one because it offered several opportunities to improve while also showcasing a wide range of skills that I have learned throughout my time in the Computer Science program. It includes user authentication, inventory management, database integration, and a user-friendly interface. I was able to show my ability to design and develop a complete mobile application. It showcases my abilities to work with SQLite databases as well as being able to implement user validation, managing a proper navigation system and creating a user-friendly interface. Object oriented programming principles were used throughout the application which helped me re-organize the code into reusable classes and methods. Overall, the app has improved by focusing on the design and maintainability of it. I was able to refactor certain portions of the code by placing validation logic into helper methods that were reusable. I also improved user input validation and replaced hard-coded text strings with string resources. The improvements that I made have made the application easier to understand and maintain while being able to preserve the original functionality of the application.

Course Outcome Alignment

The outcomes that I wanted to meet with this enhancement were numbers two and three. I believe that I met those outcomes during this assignment. I was able to refactor certain portions of the code by placing validation logic into helper methods that were reusable. I also improved user input validation and replaced hard-coded text strings with string resources. These changes demonstrate my ability to provide professional and technical communication through a well-structured and readable code while also showing my ability to look at an existing project and identify possible issues through applying best software engineering practices.

Algorithms and Data Structures

This enhancement focused on improving how InventoryPRO organizes, searches, filters, and processes inventory information.

Algorithms and Data Structures Narrative

Artifact Description and Justification

The artifact that I chose is my InventoryPRO application. It is a mobile application that was designed on the Android platform that manages a user’s inventory. It was created for the CS-360 class in December of 2025.

I chose to use this artifact for category two because it offered several opportunities to improve how inventory data is managed and displayed. The application stores the inventory records in an SQLite database and displayed that information using an array list and recycler view. This makes it a good candidate for generating more efficient searching, sorting and filtering options. My ability to select and implement appropriate data structures to improve the user experience were demonstrated in this artifact. I was able to enhance the application by creating a complete inventory list and a displayed list which allows users to search by item number, description and location. It also allowed a user to flip a switch to display items that fell under the low stock criteria and to be able to sort through the items in an ascending/descending order, by quantity or location.

The application improved through the updates of the search, sort and filter options. It started out only allowing a user to search for an item so this was a great way for users to find items through multiple criteria.

Course Outcome Alignment

I had intended to demonstrate outcomes two and three for this category. I was able to design and implement new search, sort and filter algorithms that improved the applications functionality. I also demonstrated selecting the appropriate data structures which included separating complete and display inventory list while evaluating the tradeoffs between performance and memory usage. I believe both outcomes were met and have no changes to my current course of action.

Milestone Reflection

During this enhancement I gained some insight on why selecting the appropriate data structures can improve the overall user experience and functionality of the application. Creating complete and display inventory lists allowed me to perform the different functions like searching, sorting and filtering while maintaining the original list. This was a great way to learn about using multiple algorithms to create a more flexible user experience.

The initial problems that I had were integrating the low stock switch and the spinner for the drop-down filtering menu. I quickly figured out that I was not fully initializing them in the proper areas, but after some debugging, I was able to make them work.

This enhancement was the perfect opportunity to work step by step and add each feature one at a time to ensure that I was able to catch mistakes early on. I prefer working this way because it helps me take my time and not feel overwhelmed when there is a good amount of work to be done. Careful planning and testing throughout the project were reinforced during this enhancement.
